# AI Agent 作战大屏 — 前端原型设计简报（3 套方案共用）

## 1. 产品与场景
**DSH Video Workbench** 是一个 AI 视频工作台插件。它可以挂在 DeepSeek Harness、Claude Code、Codex 等智能体里使用，也可以不接任何智能体，直接在浏览器打开 `http://127.0.0.1:4399` 的独立网页。
主要用户是**零基础创作者**：输入一句话主题、导入素材，点“一键出片”，多智能体团队就自动完成策划、剪辑、配音混音、动效编程、质检渲染，输出 MP4。

“AI Agent 作战大屏”是插件的主界面。现在的界面平淡死板，参数到处堆砌，交互体验差，也看不出 Agent 在协同干活。
这次要做 3 套风格完全不同的**可交互 HTML 原型**，给用户挑一套。选定后才会正式改插件代码，所以原型只做表现层，用模拟数据驱动即可。

这些参考的共同点：
- 中央是一个满幅、干净的“主舞台”可视化，四周是细线 HUD 面板。

- 镜头会运动：推近、跟随、全景。

## 3. 业务模块清单（原型里都要有入口，次要模块可以收进抽屉）
- **顶栏**
  - 品牌区。
  - 宿主切换胶囊“← DeepSeek 对话 ｜ 🎬 AI 视频工坊”。
  - 工程切换。
  - 模式页签：作战大屏 / 分步精修 / 影核广场 / 任务中心。
  - 状态灯：GPU、配音引擎、渲染队列。
  - 镜头开关：全景 / 跟随 / 近景。
  - 主题切换。
  - 设置。
  - **1280px 宽时不能溢出**：要能自动折叠成紧凑模式。
- **素材仓**（左侧）：
  - 素材类型：图片、视频、BGM 音乐、配音样本、笔记。
  - 云端生成待确认区：做成“试听/预览 → 确认入库”卡片。
  - 导入按钮、拖拽提示。
- **主舞台**（中央）：
  - 每套方案自己的视觉隐喻。
  - 内嵌一个**预览监视器**：显示当前镜头或成片，带播放、进度、3×3 抽帧入口。
- **多轨时间轴**（底部）：
  - 轨道：镜头轨（彩色片段与标题）、字幕轨、配音轨（波形）、音效轨（撞击/唰/马蹄等标记）、BGM 轨（波形）。
  - 节拍刻度：拍点，重拍加粗，高潮突降点特殊标记。
  - 播放头、缩放。
- **Agent 协同网络**：8 个 Agent，见 sample-project.json 的 agents。
  - 节点 + 连线，激活时有光脉冲。
  - 每个节点有状态：待命 / 运行 / 完成 / 异常，以及当前子任务。
- **任务中心**：
  - 当前运行：进度 %、阶段、已用时 / 预计剩余。
  - 按钮：开始、暂停/继续、停止、重试。
  - 实时日志流。
- **出片参数（必须收进抽屉 / 浮层 / HUD，主界面只保留一行摘要胶囊，如“16:9 · 1080p · 30fps · Remotion · 卡点MV”）**：
  - 渲染引擎：Remotion + Three.js / HTML5。
  - 画幅：16:9 / 9:16 / 1:1 / 4:3。
  - 画质：720p / 1080p / 2K / 4K。
  - 帧率：30 / 60。
  - 时长：AI 智能 / 30 秒 / 1、2、3、5 分钟。
  - 节奏：智能 / 舒缓 / 均衡 / 高燃。
  - 旁白模式：AI 配音 / 配音 + 踩拍 / 纯音乐卡点 MV。
  - 配乐：上传 / AI 编程配乐 / 云端音乐。
  - 主讲音色：AI 匹配或指定。
  - 数字人：关闭 / AI 主播 / 克隆本人；全屏 / 左下小窗 / 右下小窗。
  - 风格：科技锋芒 / 电影大片 / 温暖故事 / 活力潮牌 / 极简纪实 / 墨翠轻奢。
  - 平台安全区：通用 / 抖音 / 快手 / 小红书 / B 站。
  - AI 角标、模型选择。
- **其他入口**（菜单 / 抽屉 / 浮层，不必做完整页面，但要有入口和像样的空态或示意）：
  - 影核广场模板（卡片点开要能弹窗播放样片，原型里用模拟播放）。
  - 参考视频复刻与左右分屏对比。
  - 提词器真人录制。
  - 数字人克隆。
  - 配音中心（音色库）。
  - 云端媒体中心。
  - 算力体检，含 Vibecoding 八件套状态：Three.js、Anime.js、Tween.js、Ammo.js、TSL Textures、SuperCollider、Remotion、FFmpeg。
  - 品牌套件、发布包导出、LLM / TTS / 云端密钥设置。

## 4. 每套方案都必须具备的动态（功能性模拟，不能是静态图）
1. **一键出片模拟**：点击“一键出片 / RUN”后按脚本运行一遍流水线，约 60–90 秒，可循环，可被停止。
   - 策划导演：分镜卡片依次生成，同时测出节拍网格。
   - 素材剪辑：**素材从左侧素材仓被“抓取”并飞行到下方时间轴，精准落位到对应轨道和时间点**。
     - 要有抓取、携带、缓动飞行、落位吸附、落点闪光的完整过程。
     - 隐喻自定，不必是机械臂。
   - 配音混音：配音和 BGM 波形逐段出现；节拍刻度点亮；音效标记按拍点落下。
   - 动效编程：代码批次进度，可表现为代码流或镜头卡片逐个“编译点亮”。
   - 质检渲染：帧进度、响度和峰值指标、质检清单逐项打勾。
   - 最后：“成片就绪”仪式感时刻，预览监视器开始播放。
2. **Agent 协同网络实时律动**：激活节点发光；任务在节点间传递时，有光脉冲沿连线流动。
3. **镜头系统**：
   - 三种模式：全景、跟随、近景。
   - 跟随模式下，镜头自动、平滑地跟随当前正在工作的 Agent 或正在飞行的素材。可以用 transform 做平移和缩放，配景深模糊或视差。
   - 点击任意 Agent 可聚焦；按 ESC 或再次点击回到全景。
   - 快捷键 1 / 2 / 3 切换镜头模式，空格暂停或继续。
4. **时间轴活起来**：播放头走动；波形微动；重拍时整条时间轴有一次轻微脉冲。
5. **任务中心可控**：暂停后所有动画定格，继续后从断点接着跑；停止后归位；进度和预计剩余时间实时变化。
6. **参数收口**：
   - 主视觉干净。
   - 点击摘要胶囊或“参数”按钮，打开抽屉、HUD 或浮层，按组编辑参数。
   - 所有按钮、卡片、菜单、下拉框、开关、滑块用统一的设计语言：同一套圆角、描边、微光、阴影和动效时长。

## 5. 技术约束
- **单个自包含 HTML 文件**：CSS 和 JS 全部内联，图形用 SVG / Canvas2D / 原生 WebGL / CSS 3D。
  - **禁止任何外部网络请求**：不用 CDN，不下载网络字体，不加载外部图片。
  - 字体只用系统字体：`"Microsoft YaHei UI","PingFang SC","Segoe UI",system-ui`；等宽字体 `"Cascadia Mono",Consolas,monospace`；衬线 / 书法可用 `"STKaiti","KaiTi","SimSun",serif`。
- 示例数据用 `_shared/sample-project.json` 里的“霍去病 · 少年战神”工程（61 镜头、90 BPM、142.6 秒）。
  - 把需要的数据**内联**进 HTML，不要运行时 fetch，因为 file:// 下 fetch 会失败。
- 性能目标：主流笔记本 60fps。
  - 动画统一由一个 `requestAnimationFrame` 主循环驱动，用 delta time。
  - 粒子数量要克制。
  - 页面可在 `window.__fps` 暴露实时帧率。
- 分辨率：主设计 1920×1080；在 1440×900 和 1280×720 下不能溢出、不能出现横向滚动条。
- 界面文案以中文为主，可配英文小标签；数据要像真的。
- 不要有任何“AI 生成”的空洞占位文案，例如 Lorem ipsum、“这里是标题”。

## 6. 自测要求（必须做）
用截图工具检查（Chrome DevTools 协议，真实时间截图，并打印 console 错误和异常）：

```
node <tools>/page-shot.mjs <你的index.html> <输出前缀> --w 1920 --h 1080 --times 1500,6000,15000,30000 --eval "document.querySelector('[data-run]')?.click()@2000"
```
- 用 `--eval "js@毫秒"` 在指定时刻执行 JS，例如点击“一键出片”、切换镜头模式、打开参数抽屉，然后截图。
- 用 Read 工具查看生成的 png，检查画面质量。
- 要求：**0 个 console 错误或异常**；1280×720 下截一张图，确认不溢出；关键状态都截到图，包括初始态、素材飞行途中、跟随镜头推近、参数抽屉打开、成片就绪。
- 反复迭代，直到你自己觉得这是可以拿去给挑剔客户提案的作品。
- 给“一键出片”按钮加 `data-run` 属性，给镜头模式按钮加 `data-cam="overview|follow|close"`，给参数入口加 `data-params`，方便自动化检查。
