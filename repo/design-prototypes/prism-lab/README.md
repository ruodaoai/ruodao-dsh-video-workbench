# 方案 C · 棱镜实验室 PRISM LAB

**设计理念**：瑞士国际主义 / 包豪斯式的浅色高对比实验室。8 个 Agent 是光学平台上的 8 块玻璃元件（色散棱镜、恒偏棱镜、衍射光栅、道威棱镜、双凸透镜、球透镜、五棱镜、分光立方），环形排布在中央“取景器”四周，依流水线顺序恰好构成一圈 400–700 nm 色环。素材被扫描成一束白光，射入“素材剪辑”棱镜后分光成光谱扇，沿镜面导轨垂直落到光谱时间轴的精确轨道与时间点，凝结成光带；成片时 8 束色光重新汇聚成白光，取景器曝光后开始播放。

**色板**：暖白底 `#F2F1EC` + 8px/48px 细网格，墨黑 `#111111`；强调色群青 `#2F37FF`、信号橙 `#FF5A1F`（播放头 / 高潮突降 / 锁焦）、荧光青柠 `#C8F53B`（完成）。光谱色 `#6B2BFF → #F0284A` 只用于光束、光带和 Agent 识别色。面板为磨砂玻璃 + 1px 锐利描边 + 柔和投影，统一圆角 3/6px、动效 120/240/480ms。

**交互清单**
- 一键出片（`data-run`）：约 80 秒脚本化流水线，含策划测拍与分镜、6 次素材光束飞行落位、云端补位、BGM/配音逐段扫描、音效按拍点下落、16 批 TSX 编译点亮（含一次 tsc 报错与修复）、渲染帧进度与响度/峰值/7 项质检、成片白光曝光；开启“循环”后 16 秒自动重跑。
- 镜头 `data-cam`：全景 / 跟随（自动追踪当前光束或棱镜，1.7–1.9× 推近，画布景深 + AF 锁焦环，时间轴同步自动开窗）/ 微距（2.9×）。点击任意棱镜或标签聚焦并弹出 Agent 数据卡，Esc 或再次点击回全景。
- 参数收口：舞台顶部 HUD 胶囊（`data-params`）展开为“参数控制单”，含分段控件、刻度滑块（时长）、旋钮（节奏）、下拉、开关、风格色卡、数字人位置示意；画幅/平台安全区/数字人会实时反映到取景器。
- 时间轴：滚轮缩放、Shift+滚轮/拖拽平移、点击定位播放头；重拍脉冲、高潮突降标记、波形微动。
- 其他入口：影核广场（模板卡 → 模拟播放器）、分步精修、任务历史、实验工具九宫格（参考复刻左右分屏对比、提词器录制、数字人克隆、配音中心、云端媒体、算力体检含 Vibecoding 八件套、品牌套件、发布包、密钥设置）、云端待确认卡（试听/预览 → 确认入库）、导入与拖拽、3×3 抽帧、熄灯夜间模式。

**快捷键**：`1/2/3` 全景/跟随/微距 · `空格` 暂停/继续（全部动画定格）· `R` 一键出片 · `P` 参数控制单 · `Esc` 关闭浮层/回全景 · `N` 熄灯 · `G` 3×3 抽帧 · `T` 实验工具 · `[ ]` 时间轴缩放 · `F` 适配全长 · `?` 快捷键表。

**自动化钩子**：`window.__fps`；`__prism.seek(秒, 'overview'|'follow'|'close', 冻结?)` 确定性快进到流水线任意时刻，`__prism.quality('high')` 关闭自适应降级，`__prism.freeze()` 冻结模拟时钟便于截图。

**已知限制**
- 纯表现层原型：数据来自内联的示例工程，画面为程序化绘制的剪影海报帧，不接真实后端、不发任何网络请求。
- 自适应“低配保护”：帧间隔变差时自动降为半帧率并关闭景深与胶片颗粒（右下角显示 ECO）。
- 在本机无 GPU 的 headless SwiftShader 截图环境中，CSS `backdrop-filter`+`mask`、平滑滚动、GPU 画布都会让截图卡死，因此景深改为画布内实现、画布改为 CPU 渲染、遮罩层不用背景模糊；机器高负载时截图常比墙钟晚数十秒，故 `shots/` 关键态用 `seek+freeze` 确定性截取，`brief-*.png` 为简报原命令的实时截图。
- 1280×720 下素材仓仅显示约 3 张卡片（可滚动），舞台角标与部分英文副标签自动隐藏。
