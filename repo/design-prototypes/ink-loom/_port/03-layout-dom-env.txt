/* ══════════════ 6. 音频包络（BGM / 旁白；由节拍、突降与字幕长度合成，用于波形与监视器） ══════════════ */
const ENV_SR = 40;
let BGM_ENV = new Float32Array(8), VOICE_ENV = new Float32Array(8), VOICE_SEGS = [];
function buildEnvelopes() {
  const n = Math.ceil(DUR * ENV_SR) + 4;
  BGM_ENV = new Float32Array(n); VOICE_ENV = new Float32Array(n); VOICE_SEGS = [];
  const D = DROPS.length ? DROPS : [];
  const sec = (t) => {
    let lvl = 0.42 + 0.06 * Math.sin(t * 0.31);
    if (D.length) { const first = D[0]; if (t < first) lvl = 0.24 + 0.24 * (t / Math.max(0.1, first)); for (const d of D) if (t >= d && t < d + 18) lvl = Math.max(lvl, 0.78 - (t - d) * 0.012); }
    const tail = DUR - t; if (tail < 8) lvl *= Math.max(0.25, tail / 8);
    return lvl;
  };
  for (let i = 0; i < n; i++) { const t = i / ENV_SR; BGM_ENV[i] = sec(t) * (0.6 + 0.16 * noise1(t * 6.3, 3) + 0.1 * noise1(t * 21, 5)); }
  BEATS.forEach(([tb, st]) => { const i0 = Math.floor(tb * ENV_SR); for (let j = 0; j < 22; j++) { const i = i0 + j; if (i < 0 || i >= n) continue; const d = i / ENV_SR - tb; if (d < 0) continue; BGM_ENV[i] += (st ? 0.42 : 0.24) * Math.exp(-d * 9); } });
  D.forEach((td) => { for (let i = Math.floor((td - 1.6) * ENV_SR); i < (td + 1.2) * ENV_SR; i++) { if (i < 0 || i >= n) continue; const d = i / ENV_SR - td; BGM_ENV[i] += d < 0 ? 0.25 * Math.pow(1 + d / 1.6, 3) : 0.45 * Math.exp(-d * 3.5); } });
  for (let i = 0; i < n; i++) BGM_ENV[i] = clamp(BGM_ENV[i], 0.03, 1);
  const mv = /subtitle-mv/.test(PROJECT.narration || '');
  SCENES.forEach((s) => {
    if (s.dur < 0.6 || mv || !(s.hasVoice || s.sub)) return;
    const len = Math.max(1, Math.min(40, (s.sub || '').length || 6)), t0 = s.t0 + 0.1, t1 = Math.max(t0 + 0.2, Math.min(s.t1 - 0.08, t0 + 0.2 + len * 0.2));
    VOICE_SEGS.push({ sc: s.i, t0, t1, n: len, real: !!s.hasVoice });
    for (let k = 0; k < len; k++) {
      const tc = t0 + ((k + 0.5) / len) * (t1 - t0), a = 0.55 + 0.45 * hash(s.n * 31 + k);
      for (let i = Math.floor((tc - 0.12) * ENV_SR); i <= (tc + 0.12) * ENV_SR; i++) { if (i < 0 || i >= n) continue; const d = (i / ENV_SR - tc) / 0.085; VOICE_ENV[i] = Math.max(VOICE_ENV[i], a * Math.exp(-d * d)); }
    }
  });
}
const envAt = (arr, t) => { const f = t * ENV_SR, i = Math.floor(f); if (i < 0 || i >= arr.length - 1) return 0; return lerp(arr[i], arr[i + 1], f - i); };
const envMax = (arr, ta, tb) => { let m = 0; const i0 = Math.max(0, Math.floor(ta * ENV_SR)), i1 = Math.min(arr.length - 1, Math.ceil(tb * ENV_SR)); for (let i = i0; i <= i1; i++) if (arr[i] > m) m = arr[i]; return m; };
